YouTube arama bağlantısı ayarları

Arama sonuçlarını RAMÇO içinde listelemek için Google Cloud Console'dan YouTube Data API v3 anahtarı gerekir. Anahtar bu cihazın tarayıcısında saklanır; herkese açık dağıtımda güvenlik için sunucu tarafında saklanmalıdır.

Normal YouTube şarkıları aranır. Video, resmî YouTube oynatıcısında RAMÇO içinde açılır.
Not: Yerel HTML dosyalarında (file://) YouTube 153 hatası görülebilir. Gömülü oynatıcı için RAMÇO'nun HTTPS adresinde çalışması gerekir. Bazı videolar sahipleri tarafından gömülü oynatmaya kapatılmış olabilir.

Vokal azaltma düğmesi korunmuştur. Yerel ses dosyalarında çalışır; YouTube'un korumalı gömülü oynatıcısının sesini tarayıcı güvenlik sınırları nedeniyle RAMÇO işleyemez.
